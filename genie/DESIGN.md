# WISH 设计说明 —— 为什么这样设计

> 一句话：**先读懂一个家，再把它变出来。**
> 客人第一次到展厅，先和熊猫精灵「潘吉」玩 5 分钟占卜，把心里的家说出来；
> 设计师接着把平面图 + 他的答案，马上变成看得见、能换材质、能拖太阳的 3D 概念。

---

## 0. 要解决的问题

第一次见面时没有任何「看得见」的东西，于是：

- 客人说不清楚（「我要简约一点的」—— 每个人的简约都不一样）；
- 设计师只能猜，第一版方案常常方向就错；
- 细谈阶段反复改，浪费双方时间，也伤信任。

所以 WISH 做两件事：

1. **把需求问出来** —— 用游戏的方式，让客人在轻松、有仪式感的状态下，说出真实偏好、真实的东西数量、真实的雷区；
2. **把需求变出来** —— 当场生成 3D 概念，让对话从「空讲」变成「对着看得见的东西讲」：*这是不是你要的？*

---

## 1. 两个分开的功能

| | 梦想家占卜 `quiz.html` | 3D 梦想工作室 `studio.html` |
|---|---|---|
| 给谁 | 客人（展厅 iPad / 手机） | 设计师、销售（电脑 / 展厅大屏） |
| 多久 | 约 5 分钟 | 不限 |
| 产出 | 「专属梦想家概念蓝图」（客人版 + 设计师版）、分享海报、WhatsApp 摘要 | 3D 概念、带品牌的高清概念图、分享链接、演示模式 |
| 能单独用吗 | 能 | 能（没有占卜档案时用三个情绪预设） |

两者用一条链接串起来：蓝图页「在 3D 里看见它」→ `studio.html#p=<档案>`。档案里的材质、收纳量、
生活习惯（神台、宠物、在家办公、鞋量、衣柜量）会自动套进 3D 的材质和家具摆放。

## 2. 用《快思慢想》的逻辑设计占卜

卡尼曼把人的思考分成两套系统：**系统 1** 快、凭直觉、不费力；**系统 2** 慢、要计算、很耗能。
问卷之所以无聊又不准，是因为它**一直在逼系统 2 回答系统 1 才答得好的问题**（「你喜欢什么风格？」），
却又**让系统 1 去回答系统 2 才答得准的问题**（「你大概需要多大的衣柜？」—— 随口一说）。

WISH 把两者分开，并把书里的概念一个个落成具体功能：

| 心理学概念 | 意思 | 在 WISH 里的做法 |
|---|---|---|
| **系统 1 / 系统 2** | 快直觉 vs 慢思考 | 第一张牌「直觉」：12 组图片二选一，3 秒进度条（不惩罚，只是提示「别想」）。第三张牌「宝藏」：潘吉换上放大镜，明说「现在请慢下来」，数鞋、数衣柜、数书。|
| **替代效应** | 人遇到难题会偷偷换成简单题来回答 | 我们主动替客人换：不问「你喜欢什么风格」，问「哪一个房间让你想马上躺下」「光着脚想踩在哪里」。风格由我们从答案推算（四条轴 → 16 张牌）。|
| **认知放松** | 越流畅、越熟悉，越愉快、越信任 | 一屏一题、大图少字、生活语言；按钮大、反馈快（音效、翻牌、星星）。|
| **反应时** | 越快 = 越确定 | 每题记下毫秒数：秒选（< 1.6 秒）权重 ×1.25，犹豫（> 3.5 秒）×0.8。设计师版蓝图列出「秒选」项目，并判断客人是**直觉型**（提案给 2 个方向就好）还是**比较型**（准备实样与对比表）。|
| **框架效应** | 同一个问题，换个说法答案就不同 | 用生活场景提问：「星期六早上 10 点你在哪里」「推开家门第一件事」「门铃突然响了最想藏什么」。|
| **损失厌恶** | 对讨厌 / 失去的东西，比喜欢的更敏感、更确定 | 第五张牌「禁忌」只问**绝对不要什么**（颜色、质感、玻璃柜门、开放层板…）；系统会自动把踩雷的材质换成最接近的安全选项。「门铃响了」那题问的是痛点，而不是愿望。|
| **聚焦错觉** | 想到什么，什么就显得最重要 | 第四张牌「三个愿望」：12 个愿望只能选 3 个，并按顺序。逼出真正的优先级，而不是「每样都很重要」。|
| **锚定**（善用，也防误用） | 第一个看到的数字会影响判断 | 数鞋子时实时换算成「鞋柜 ≈ 2,100mm」—— 用工程常识帮客人估得更准；**预算不在占卜里问**（避免被我们的数字锚定，预算仍在需求卡 / 面谈时谈）。|
| **眼见即一切（WYSIATI）** | 人只根据眼前的信息下判断 | 这正是 3D 工作室存在的理由：客人只会对看得见的东西有判断，所以要让他马上看见。|
| **峰终定律** | 体验被记住的是最高点和结尾 | 峰：洗牌 → 一张牌升起、翻面、金色星屑。终：盖着「潘吉认证」印章的蓝图 + 熊猫道别 + 可以带走的海报。|
| **经历自我 vs 记忆自我** | 回忆比当下更决定人的选择 | 蓝图链接 + 分享海报：客人回家打开 / 发给家人，体验再发生一次（也是口碑）。|
| **光环效应** | 一个好印象会扩散到其他判断 | 精致的牌面、可爱的熊猫、顺滑的动效 —— 先让客人感受到「这家公司很细心」。|

**伦理底线**：这些原理用来**帮客人说出真实需求**，不用来制造假紧迫、不在测试里推销、不锚定预算。
设计师版里「直觉型 / 比较型」的判断，是为了用客人舒服的方式沟通。

### 四条轴 + 三条暗轴

| 轴 | a 侧 | b 侧 | 影响 |
|---|---|---|---|
| 温度 | 暖 W | 清 C | 色温、木色、墙色 |
| 密度 | 简 M | 丰 L | 软装数量、留白 |
| 质感 | 朴 N | 雅 R | 自然材质 vs 石材金属烤漆 |
| 收纳 | 藏 H | 展 D | 柜门比例、玻璃展示柜、开放层板 |
| 暗轴：明度 / 线条 / 社交 | 明亮 / 圆润 / 相聚 | 沉稳 / 利落 / 独处 | 时间预设、沙发款式（弧形 / L 形）、餐桌座位数 |

16 张牌（I–XVI）每张都写成「被看见」的样子（没有坏牌）。每张牌附带：整套 3D 材质、配色、
设计语言（风格 / 色温 / 柜门 / 藏展比例）和**可以直接贴给 AI 出图的英文关键词**。

## 3. 为什么玩 The Sims 不无聊，设计房子却很累？

The Sims 的「建造模式」本质上就是室内设计，但人会玩到忘记时间。拆开看，它做对了这些事 —— WISH 照着做：

| The Sims 做对的 | 为什么让人停不下来 | WISH 3D 工作室 / 占卜 |
|---|---|---|
| **即时反馈** | 每个动作马上有结果，大脑一直拿到小奖励 | 拖材质 → 那一组表面发金光、放手马上换；数鞋 → 鞋柜马上变长；拖太阳 → 光马上走 |
| **零成本试错** | 不怕选错，才敢一直试 | 撤销 / 重做；「一键情绪」随时回去 |
| **需求条** | 一组会动的数字，告诉你「变好了」 | 情绪仪表 COZY / BRIGHT / MOODY，跟着材质和时间实时变化，还有一句话描述 |
| **时间在流动** | 有生命的世界 | 24 小时光影：清晨薄光、斜进窗的光柱、窗上的树影、夜里亮起的灯 |
| **有限而精选的目录** | 选择太多会瘫痪 | 每类约 10 个材质，按 Wood / Stone / Tile / Fabric / Paint / Metal 分好 |
| **直接操作** | 手比菜单快 | 拖材质、拖家具、拖太阳；点一下家具 = 旋转 / 换款 / 复制 / 移走 |
| **为「人」设计** | 你在照顾一个小人，所以有情感 | 家具按客人的生活自动摆：神台、宠物窝、玩具柜、书桌、鞋柜长度、衣柜长度 —— 「这是**我的**家」 |
| **小目标 + 进度** | 未完成的事会一直挂在心上（蔡格尼克效应） | 占卜的五颗星进度、「蓝图完成度」百分比 |
| **惊喜** | 不确定的奖励最上瘾 | 秒选反应、洗牌揭晓、彩蛋式的熊猫台词 |

## 4. 设计师视角：它替你做了什么

**见面前 / 见面时**

- 蓝图「设计师版」：风格、色温、柜门、藏展比例、秒选清单、英文出图关键词；
- **谈话提示**：自动找出矛盾和风险，例如
  - 天天爆炒 + 喜欢开放热闹 → 干湿分区、烟机风量；
  - 想展示 + 怕积灰 → 玻璃门 + 柜内灯带；
  - 有猫狗 + 选了丝绒 → 改科技布 / 皮革；
  - 选了深色系 + 想要明亮 → 深色只用在主题墙；
  - 需要神台 / 长辈同住 / 在家办公 / 大件多 → 对应尺寸与预留。
- **收纳蓝图**：鞋柜宽、衣柜目标宽（长挂 / 短挂 / 叠放）、书墙长度、家电台面与电器高柜、储物间建议。

**3D 工作室**

- 上传平面图（图片 / PDF）→ AI 认出房间、门、窗（Gemini，选填）→ 拖一拖校正 → 生成 3D；
- 家具按设计师规则自动摆：电视墙选最长无窗的墙、沙发离电视 2.7–3.3m、床头靠无窗墙且两侧留 50cm、
  衣柜前留 60cm、橱柜沿最长墙并避开窗、够大就做 L 形 / 岛台……
- 换材质、换情绪、换时间、挪家具，全部可撤销；下载带品牌的概念图；演示模式给展厅大屏 / 录屏宣传。

**局限（要跟客人讲清楚）**：这是**概念示意**，不是施工图；尺寸以现场量尺为准；家具是程序化的示意款。

## 5. 客人视角：第一次到展厅的 60 分钟

| 时间 | 发生什么 | 客人的感受 |
|---|---|---|
| 0′ | iPad 上「擦亮神灯」，潘吉从烟里冒出来 | 好可爱 / 有点好奇（仪式开始） |
| 1′ | 直觉之牌：12 组二选一 | 轻松、好玩、「它好像懂我」 |
| 2′ | 生活之牌：周六早上、门铃响了 | 被问到生活，而不是被考设计 |
| 3′ | 宝藏之牌：数鞋、衣柜、书、家电、大件 | 「原来要想这些」—— 被认真对待 |
| 4′ | 三个愿望 | 第一次想清楚自己最在乎什么 |
| 5′ | 禁忌之牌 + 一句话 | 说出讨厌的东西，很爽快 |
| 5′30″ | 洗牌、翻牌：「I · 暖木禅居」 | **峰值**：被看见 |
| 6′ | 蓝图（盖章）+ 海报 | 有仪式感，可以带走、可以晒 |
| 10′–50′ | 设计师打开 3D：上传平面图，套用他的材质；一起换材质、拖太阳 | 「这就是我想要的」/「这个不是」—— 具体的对话 |
| 结尾 | 下载概念图、WhatsApp 发链接 | 回家还能再看一次（记忆自我） |
