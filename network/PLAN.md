# S.T.A.R（人脉 App）规划

> 名字：**S**eek 寻找 · **T**reasure 珍惜 · **A**ssist 帮助 · **R**econnect 再联系 —— Strong Ties Are Riches。灵感来自 Starlink：你是中间的星，人脉是轨道上的卫星。

## 原始规划（灵感：康妮《如何结交比你更优秀的人》+ 卡耐基《人性的弱点》）

## Context
Wilson 想要一个**只给自己用**的人脉管理 app，用来记录每个朋友的对话、兴趣、资源、商会、见面次数、合照，然后用 **Sims 4 风格的关系图**告诉他：今天该联系谁、哪段关系在变淡、要找人帮忙时该找谁。另外还有三个功能：名片扫描与"值得认识吗"评分、酷炫的个人名片页（可以接 FoloToy 和 NFC）、半自动 WhatsApp 群发与话术建议。
这次对话只做头脑风暴和规划，**不写代码**。

## 面试结论（已确认）
| 项目 | 决定 |
|---|---|
| 使用者 | 只有自己 → 要登录，数据只有本人看得到（和 Sail CRM 的"开放团队"模式不同） |
| 跟 Sail CRM 的关系 | 完全独立，不连接；放在本 repo 的新文件夹 `network/`，单独部署（和 `crm/` 一样的做法） |
| 分级 | 组合打分：Sims 好感度（会随时间下降）＋ 康妮圈层（核心 5 / 重要 15 / 活跃 50 / 认识 150）＋ 资源价值分 |
| 设备 | 手机：在活动现场扫名片、拍合照，见面前看提示卡；电脑：周末整理；要接 **TickTick** 用时间盒排见面 |
| WhatsApp | 半自动：AI 帮每个人写不同的话，`wa.me` 链接逐个点开再发送（免费，没有封号风险） |
| 对话来源 | Plaud 录音、语音备注、WhatsApp 导出的 .txt、WhatsApp 截图，四种都要 |
| 个人名片页 | 展厅视频开场 → 本人介绍 → 公司、资源、案例 → WhatsApp 按钮 |
| 预算 | AI 费用每月 RM50 以内 |
| 先做哪个 | 人脉资料库 + 名片扫描 |
| 关系图 | 两种都要：手机上默认显示 Sims 卡片列表，电脑上看星系图 |
| "值得认识"评分的 4 个维度 | 能带来家具生意 / 是超级连接者 / 有我缺的资源 / 我能帮到他 |
| 隐私 | 全部保留（包括逐字稿），只有本人登录才能看，私密存储 |

## 技术方向（沿用 repo 现有的技术栈）
- Vite + React + Tailwind，PWA（可以装到手机桌面，能直接调用相机）
- Supabase：登录用 Auth，RLS 规则限定只有 owner 能读写；照片、名片、录音稿放 **私有** Storage bucket
- AI 调用全部走 Vercel serverless function，API key 不放在前端
- 参考 `crm/`（独立部署结构、`services/repo.js` 的数据层写法）和 `invite/`（静态页、`vercel.json`）

## 核心数据模型（第 1 阶段定稿）
人物、公司、商会/圈子、资源标签（他有的 / 他需要的 / 我能给的）、互动记录（见面、对话、来源、AI 摘要）、照片（合照、名片）、活动与出席记录、关系分数快照。

## 分阶段计划（每个阶段都开一个新对话）
| 阶段 | 内容 | 建议用的模型 / effort |
|---|---|---|
| **1 资料库 + 名片扫描** ✅ | 数据结构、登录；手机拍名片 → AI 识别 → 公司背景查询 → 4 个维度评分 →"我可以给他什么资源（家具以外）"建议；上传合照；人物详情页 | Opus 5.5 · high（地基要打稳） |
| **2 对话输入与分析** ✅ | Plaud 逐字稿导入（先确认 Plaud 有没有开放 API，没有就用分享/导出的文字）、语音备注（可以用手机键盘语音输入或 Plaud 录）、WhatsApp .txt 和截图 → AI 提取兴趣、需求、资源、情绪 → 写进人物档案 | Opus 5.5 · medium |
| **3 Sims 关系图 + 今日行动** | 好感度衰减公式、圈层对应的联系频率、"今天该找谁"、"要找人帮忙时谁有这个资源"搜索；卡片列表 + 星系图；见面前的提示卡；一键排进 TickTick（官方 Open API） | Opus 5.5 · high |
| **4 个人名片页 + FoloToy + NFC** | 可以放视频的单页名片（静态页，加载要快）、二维码；NFC 贴纸写入链接；FoloToy 开源固件（ESP32-C3、240×320 屏幕）里加一个显示二维码的小应用 | 网页：Sonnet 5.5 · medium；FoloToy 固件：Opus 5.5 · high |
| **5 WhatsApp 半自动群发 + 话术** | 按标签、圈层选人 → AI 帮每个人写不同的话（按卡耐基原则：叫名字、提他感兴趣的事、真诚赞美）→ 生成卡片 → 逐个点开 `wa.me`；记录活动出席；根据回应调整以后的话术、标出"要避开的话题" | Sonnet 5.5 · medium |

**什么时候开新对话：** 每个阶段开一个新对话，开头说一句"读 `network/PLAN.md`，做第 X 阶段"。如果同一阶段里 PR 合并了，或者对话已经很长（开始要回头重复解释前面的内容），也开新对话。

**app 里的 AI 怎么选模型（控制在 RM50/月）：** 名片识别、日常摘要用 Haiku 5.5；深度分析、公司背景、话术用 Sonnet 5.5（只在按"深度分析"按钮时才跑）；公司背景查一次就存起来，不重复查。

## 待确认风险
- ~~Plaud 有没有给第三方 app 用的 API~~ → 查过了（2026-11）：没有给个人用的公开 API（官方指向 Plaud MCP / CLI；Developer Platform 是给硬件厂商的 Embedded SDK）→ 用汇出的 TXT / SRT
- FoloToy 背面的 NFC 能不能写入还不清楚 → 先准备 NTAG215 贴纸作为保底方案
- WhatsApp 导出的聊天记录含有对方的个人资料 → 私有存储 + 只有本人能看（用户已经选择全部保留）

## 验证方式（每个阶段结束时）
- 手机上真机测试：扫 3 张真实名片，检查识别准确率和评分理由
- 用 Playwright 截图：手机宽度 + 电脑宽度
- 换一个账号登录，确认看不到任何数据（检查 RLS）
- 每月 AI 费用：在 app 里显示累计用量
