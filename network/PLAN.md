# SPACE（人脉 App）规划

> 名字：**S**eek 寻 · **P**rofile 识 · **A**ssist 助 · **C**onnect 连 · **E**volve 长 —— Give Every Tie Its Space。灵感来自 Starlink：你是中间的星，人脉是轨道上的卫星。（以前叫 S.T.A.R）

## 原始规划（灵感：康妮《如何结交比你更优秀的人》+ 卡耐基《人性的弱点》）

## Context
Wilson 想要一个**只给自己用**的人脉管理 app，用来记录每个朋友的对话、兴趣、资源、商会、见面次数、合照，然后用 **Sims 4 风格的关系图**告诉他：今天该联系谁、哪段关系在变淡、要找人帮忙时该找谁。另外还有三个功能：名片扫描与"值得认识吗"评分、酷炫的个人名片页（可以接 FoloToy 和 NFC）、半自动 WhatsApp 群发与话术建议。
这次对话只做头脑风暴和规划，**不写代码**。

## 面试结论（已确认）
| 项目 | 决定 |

## 技术方向（沿用 repo 现有的技术栈）
- Vite + React + Tailwind，PWA（可以装到手机桌面，能直接调用相机）
- Supabase：登录用 Auth，RLS 规则限定只有 owner 能读写；照片、名片、录音稿放 **私有** Storage bucket
- AI 调用全部走 Vercel serverless function，API key 不放在前端
- 参考 `crm/`（独立部署结构、`services/repo.js` 的数据层写法）和 `invite/`（静态页、`vercel.json`）

## 核心数据模型（第 1 阶段定稿）
人物、公司、商会/圈子、资源标签（他有的 / 他需要的 / 我能给的）、互动记录（见面、对话、来源、AI 摘要）、照片（合照、名片）、活动与出席记录、关系分数快照。

## 第 4 阶段：扫码留资料（2026-11-17 确认要做）
目标：活动上不用交换名片，对方扫我的二维码 → 看到我的名片 → 留下他的资料 → **自动加进 SPACE**，我不用手动输入。

**对方看到的（公开页，例：`/c`，不用登入）**
1. 我的名片：照片 / 短视频、名字、职位、公司、一句话介绍；按钮「存我的联络方式」（下载 vCard）、「WhatsApp 我」
2. 「留下你的联络方式」表格：名字（必填）、手机 / WhatsApp（必填）、公司、职位、邮箱、「我们在哪里认识」（选填）；可以选拍一张他的名片代替打字
3. 同意条款打勾（马来西亚 PDPA：说明资料只给我本人用，可以要求删除）
4. 送出后：「谢谢！」+ 一键 WhatsApp 我，预设讯息「Hi Wilson，我是 ___，刚刚在 ___ 认识」

**我这边（SPACE 里）**
- 自动建成一个人：圈层「认识」、标签「扫码」、`how_met` / `met_on` 自动填；有拍名片的话照扫名片流程用 AI 读
- 已经存过的人（电话末 9 码 / 邮箱一样）→ 不重复建，只更新资料 + 记一笔互动「扫码留资料」
- 「人脉」页顶部显示「新朋友 N」，点进去可以快速确认、补备注、或删掉（防乱填）
- **活动模式**：每个活动一个专属二维码（`/c?e=<活动>`），扫码的人自动记到那个活动的出席名单（`events / attendance` 表已经建好）
- 不自动跑「深度分析」（花钱），想深入的人再按

**安全**
- 公开页不能直接写资料库（所有表都是本人才能读写）→ 走 serverless function `/api/inbox`，在服务器端用 `SUPABASE_SERVICE_ROLE_KEY`（Vercel Sensitive 变数，前端拿不到）写进 `OWNER_EMAIL` 那个帐号底下
- 防乱填：隐藏栏位（honeypot）+ 同一 IP 每小时限次 + 可选 Cloudflare Turnstile；栏位长度限制；名片照片只收 jpeg / png / webp、≤ 10MB
- 需要加的环境变数：`SUPABASE_SERVICE_ROLE_KEY`（必需）、`TURNSTILE_SECRET_KEY`（可选）

- 每月 AI 费用：在 app 里显示累计用量
