# RICCIONE REKA · Studio

内容工作台 —— **构思 / 剪辑 / 发布** 一条龙。

> 核心用法：**上传一条你想要那种感觉的参考视频 + 你自己的原片和案例图 → 拿到一条可以直接去渲染的剪辑方案。**

调研过程和四条渲染流水线的对比见 [`RESEARCH.md`](./RESEARCH.md)。

---

## 它解决什么

你看到一条爆款视频，心想「我也想拍这种」。然后卡住 —— 因为「那种感觉」是一堆说不出口的东西：
第几秒切、字幕几个字一跳、调色偏哪边、钩子在哪一帧。

Studio 把这些拆出来变成可执行的东西：

| | 干什么 | 出什么 |
|---|---|---|
| **构思** | 拆参考视频 | 配方：结构骨架、逐拍时间码、节奏、调色、字幕规律、**素材购物清单** |
| **剪辑** | 配方 × 你的素材 | 时间轴（精确到第几秒切进切出）、缺口清单、`edl.json`、`master.srt`、分镜表、交接指令 |
| **发布** | 打包 | 5 条不同角度的标题、正文、标签、封面（可直接出图）、第一条评论、跨平台改写 |
| **趋势** | 选题 | 格式雷达（讲机制不讲玄学）、红海/盲区、8–10 个能开工的选题、内容日历 |

**它不渲染视频**，它想清楚怎么剪，然后把方案翻译成 [video-use](https://github.com/browser-use/video-use) /
[HyperFrames](https://github.com/heygen-com/hyperframes) / [Vyra](https://vyra.ai) 吃得下的格式。
这是刻意的分工：浏览器不适合跑 ffmpeg，但非常适合做判断和给你看。

## 一条完整的路

1. **构思** — 选平台 → 传参考视频 → 「拆解」
   拿到配方和素材清单。清单每一条都是可执行的拍摄简报（「手持，从关着的柜门推近到 30cm，按下反弹器，2 秒，顺光」）。
2. **剪辑** — 把手上的原片和案例图拖进来
   每条素材先过一遍 AI：里面是什么、哪几秒能用、有什么毛病。然后「排剪辑」。
3. **看一遍** — 点「走一遍」
   用你真实的素材按时间轴顺序播一遍。节奏不对当场就能看出来，省掉一整轮真渲染。
4. **出片** — 下载 `edl.json` + `master.srt`，复制交接指令，在素材目录开 Claude Code 粘贴
   （或者复制 Vyra 指令，在浏览器里让 Claude 直接搭时间线。）
5. **发布** — 生成对应平台的发布包，封面可以直接出图。

## 参考视频是怎么被「看懂」的

| 情况 | 走哪条路 | 能不能听到声音 |
|---|---|---|
| < 14MB | 整条视频内联给模型 | ✅ 有声音，转写 + 音乐能量都能分析 |
| ≥ 14MB | 先试 Files API 断点上传 | ✅ 同上 |
| 上传通道被 CORS 挡住 | **本机抽 18 帧**分析 | ❌ 声音相关的判断会标「推测：」 |

三条路都**不会把原片传到我们的服务器** —— 要么直连 Google，要么根本没离开你的浏览器。

## 数据放哪

- **API key** — 只在本机 `localStorage`，直连 `generativelanguage.googleapis.com`，不过任何中间服务器
- **项目存档** — 本机 IndexedDB，存的是「脑子」（配方 / 方案 / 文案 / 素材元数据 + 缩略图）
- **原始视频** — **不存**。几百 MB 塞进 IndexedDB 只会把浏览器拖垮。重开项目后把原文件再拖进来即可继续预览和导出。

登录用的是和「溪岸 Render」同一套账号密码。

## 开发

```bash
cd studio
npm install
npm run dev       # 本地开发
npm run build     # 构建到 dist/
npm run preview   # 预览构建产物
```

需要一个 Google AI Studio 的免费 API key：<https://aistudio.google.com/apikey>
拆一条参考视频大约 US$0.01–0.05。

部署见 [`DEPLOY.md`](./DEPLOY.md)。

## 已知边界

- **趋势那一屏不接实时数据。** 它做的是「格式为什么有效 + 你该怎么做出不一样的」。
  把你最近刷到的爆款粘进输入框，输出质量差两个档次 —— 模型的知识有截止日期，你的观察没有。
- **封面出图不写中文大字。** 模型写中文容易出错别字，所以 prompt 只负责画面和留白，大字自己叠。
- **抽帧模式听不到声音。** 涉及口播和音乐的判断会标「推测：」，自己核一下。
- **时间码是模型看出来的，不是解码出来的。** 导出的 in/out 已经夹回素材真实时长内，
  但真正的精度来自渲染端用词级时间戳做吸附 —— 这也是推荐走 video-use 的原因。
