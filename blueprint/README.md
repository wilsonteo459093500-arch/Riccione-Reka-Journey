# UKIR STUDIO · 设计师提案工作台

> by RICCIONE REKA · 溪岸 SAIL

设计师做好方案（WPS / PowerPoint 导出的 PDF）→ **丢进来 → 自动生成「Dreamhouse Blueprint」品牌提案 PPT**。
版式是「格物」：米白纸面、明亮的大图、严格的网格，公司封面 / 品牌 / 公司 / 服务页是一本**品牌画册**；
方案页由 PDF 自动识别排版（满版大图与图文页穿插），**方案章节的封面用 Material Board**（AI 实拍级材质摆盘）。
一份提案可以出 **华文 / English / 中英** 三种版本（中英并重：中文、英文一样大）。导出的是**可编辑的 .pptx**，
在 PowerPoint / WPS / Keynote 里继续改字、换图都没问题。

目的：**缩短做提案的时间，同时让提案更好看、更好讲。**

> 新版 UKIR STUDIO 接替旧版（`/render`：AI 效果图 / 设计顾问 / Material Board）。旧版的 **Material Board 功能完整搬到这里**，
> 不做提案也能单独用；部署在旧版同一个网址时，设计师本机的材质库、画板、登录与 API key 会自动搬过来。
> 上线见 [`DEPLOY.md`](./DEPLOY.md)，代码结构见 [`ARCHITECTURE.md`](./ARCHITECTURE.md)。

## 设计师怎么用

1. **上传方案 PDF** —— 自动识别：楼层、每页的空间名、效果图、材料样板（名称 / 编号 / 待确认）、标注说明；客户名、地点、日期从文件名读。
2. **检查与修改** —— 左边整套页面，中间所见即所得，右边改字 / 换图 / 换版式（满版大图 ↔ 图文）/ 调材料；点画布上的字直接跳到对应输入框。
   材料在「材料清单」里改一次，所有页面同步。可开「对照原稿」逐页核对。有 API key 时可一键「AI 润色标题」。
   版面不合适时打开中间工具条的 **「调整版面」**：点照片或文字 → 拖动换位置、拖角改大小；照片还可以在框里拖动取景、缩放、
   一键「整张显示（不裁）」。调过的页在左边标「手调」，随时可以「恢复自动」；导出的 PPT 和预览一致。
   顶栏切换 **华文 / English / 中英**：英文写在每个中文栏下面的 EN 框里（整套共用的翻译记忆），缺英文的可以一键「AI 翻译」。
3. **Material Board 封面** —— 本案材料自动导入画板，可再加道具（客户故事），AI 实拍排版出图 → 「设为方案封面」。
   也可以直接上传现成的 Material Board 图片。
4. **3D 立体图（可选）** —— 上传平面布置图（图片、PDF，整张 PPT 页也行）→ AI 自动框出图纸范围（可拖动调整）→
   AI 先在图纸上框出墙、门窗、柜子家具（2 次看图；也可以自己画）→ 在图纸上拖动核对 → **程序按核对过的坐标出图**
   （正俯视 / 立体俯视 / 斜角立体，墙高可调），所以位置不会跑。材质可以贴图：从材料清单选、上传照片，或让 AI 只出一小块材质样本。
   保存后一键插进提案（或当楼层章节页背景）。
5. **导出 PPT** —— 一键下载 `.pptx`（导出时可另选语言，不改项目）；还可以下载项目备份（含 Material Board 画板）发给同事。
   PPT 用的字体：思源黑体 Light（Noto Sans SC）、Hanken Grotesk、Ysabeau Office —— 导出弹窗里有下载链接；发给客户建议另存 PDF。

### 只做 Material Board（不做提案）

首页「Material Board · 材质排版图」：和旧版 UKIR STUDIO 一样 —— 我的材质库（上传 / AI 生成无缝样片）、多块画板、拖拽 / 缩放 / 旋转、
整齐网格 / 杂志拼贴、AI 抠图、编号图例、标题、AI 实拍排版，下载高清 PNG（带 logo 水印）发 WhatsApp / 社媒 / 打印。

## 原稿怎么做，识别最准

| 原稿习惯 | 生成结果 |
|---|---|
| 每页左上角写「空间名 + 英文」，如 `客厅 LIVING AREA`、`主人房U形衣橱+化妆台（白天）` | 标题「客厅」「主人房 · U 形衣橱 · 化妆台 · 白天」+ 英文小标题 |
| 楼层分隔页写 `GROUND FLOOR 一楼设计图`（`1st Floor`、`1/F`、`二楼` 也认得） | 楼层章节页「一楼」+ 本层空间清单 |
| 材料样板图旁边 / 上面写「柜体 & 柜门 / 浅川橡 AG273 /（待确认）」 | 材料行：样板 + 用途 + 名称 + 编号；待确认会在编辑器里标出 |
| 效果图上的箭头标注文字 | 变成页面上的「设计说明」 |
| 文件名 `2026.8.6 Muar - Mr Lau - GF L1.pdf` | 客户 Mr Lau、地点 Muar、日期 2026 · 08 |

也认得：标题写在页面底部 / 效果图下方、竖版 A4、16:9、旋转 / 裁切过的图片、每页都有的页脚（网址、品牌、页码会自动忽略）。
「导出为图片」或扫描的 PDF 读不到文字，效果图照样导入，空间名和材料需要手填（会提示）。

## 数据与费用

- **全部在浏览器本机完成**：PDF 不上传任何服务器；项目与图片存在本机 IndexedDB。
- **AI 是可选的**：不填 key 也能完整「上传 → 编辑 → 导出」。AI 润色 / Material Board 实拍排版 / 3D 立体图用 Google Gemini（与旧版 UKIR STUDIO 同一种 key），按量计费。
- 登录用旧版 UKIR STUDIO 同一组账号密码。

## 公司页（品牌画册）的文字与照片

公司页（封面、目录、品牌、公司、服务、封底，共 19 页）写在 `src/engine/b/company.js`：

- **文字**：`COMPANY_PAGES_B` 里每页的栏位都有中文、英文默认稿。设计师在编辑器里改的字只影响那一份提案。
- **照片**：每个照片位一行（`PHOTO_SLOTS`），默认图在 `PHOTOS`。换品牌照片：把高清图（长边 ≥ 2400 px，不压暗）放进
  `public/template/b/`，在 `PHOTOS` 加一行，再把对应照片位指过去（`PHOTO_SLOTS` 的注释里写了建议先换的顺序）。
- 项目相关文字（客户、地点、日期、楼层、方案名）在默认稿里是 `{{token}}`，会按项目自动填写。

网格、字级、颜色只在 `src/engine/b/kit.js` 定义，方案页（`b/design.js`）和公司页都只用它来拼。

## 开发

```bash
cd blueprint
npm install
npm run dev      # 本地开发（会先把 pdf.js 的中文 CMap 复制到 public/pdfjs/）
npm test         # 纯函数 + 导出结构测试（Node）
npm run build    # 生产构建到 dist/
```
