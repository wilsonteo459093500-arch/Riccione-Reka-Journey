# SAIL 溪岸 · Material Mood Board Generator

把方案效果图变成 **Minotti 式材质情绪板**（俯拍平铺 + 色板 + 材质条 + 编辑级排版），
一键导出 1500×2000（3:4）高清 PNG，用于客户提案 / 社媒 / 物料板。

> 独立单文件 app，零依赖、零构建。两种访问方式：
> - **本地**：直接用浏览器打开 [`index.html`](./index.html)。
> - **线上**：放在根 Vite app 的 `public/` 下，部署后访问 **`<部署域名>/moodboard/`** 即可（无需单独部署）。

## 用法

1. 浏览器打开 `index.html`（或部署后访问）。
2. **＋ 上传效果图**（支持多张 / 拖拽 / `Ctrl+V` 粘贴）。
3. 选版式：
   - **叠层拼贴** — 自动从图片裁出材质特写，做高级层叠拼贴（默认）。
   - **整图底图** — 用建E网AI / 即梦出的整张平铺图占满拼贴区，本工具只负责叠加品牌与排版；上传后在缩略图里点选一张设为底图。
4. 自动取色生成 6 色色板，可手动改名 / 改色；材质标签、文案、品牌句均可编辑。
5. **⤓ 导出高清 PNG**。

## AI 文案（可选）

填入 **Anthropic API Key** 后点 **✦ AI 生成文案**：用 Claude Vision 读图，自动产出
英文叙述、中文氛围句、风格关键词、6 个配色名、7 个材质名。

> ⚠ 浏览器直连仅适合**本地自用**。上线请改走后端代理，不要把 key 暴露在前端。
> Key 仅存于本机 `localStorage`。

## 设计要点（所见即所得）

- **单一渲染引擎** `renderBoard(ctx, S)`：屏幕预览与导出离屏 canvas 共用同一套绘制代码，
  设计坐标固定 `750×1000`，`S` 为缩放倍率 —— 预览即最终效果。
- **编辑级字体**：标题 `Fraunces`（衬线）+ 标签 `DM Sans`；canvas 导出前 `await` 字体就绪，避免回退默认字形。
- **自然光晕 + 柔影**：左上柔光、右下轻暗角、样块漫反射投影，让平铺读起来像被自然光拍下。
- **取色**：5-bit 分箱 + 去纸面背景 / 高光 + 去近似 + 按明度排序，得到协调的材质色阶。

## 出图 Prompt

点 **✎ 出图 Prompt** 生成中英双语提示词，可贴去建E网AI / 即梦 / Midjourney 直接出整张平铺图，
再回到本工具用「整图底图」模式叠加品牌排版。
