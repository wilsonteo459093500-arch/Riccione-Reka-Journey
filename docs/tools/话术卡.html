先填价格表

每家户型不同、要的柜子也不同，所以我们不报一个总价，而是报按空间的起步价加按房型的常见区间 —— 客人自己会加、自己会对号入座。这张表由老板定一次、全公司统一，填完存在这台手机上。话术里带红色虚线的地方还没填，不要发出去。

尚未填写

怎么定：导出最近 12–24 单已成交，每单记「房型／做了哪些空间／板材档次／合同额」。按空间起步价＝只做该空间那几单的最低额；房型区间＝该房型的 P25–P75；A＝最小的全屋成交额向下取整。样本不够就用「最小可交付组合」倒推。

给区间的两个坑

上限一定要给够。下限是筛选器，上限是保护。客人最后收到的正式报价一旦超出你给过的上限，前面建立的信任会一次性归零 —— 所以话术里都留了「做得很满的会更高」这个不封顶的尾巴，别删掉它。

慎用「每尺多少钱」。客人会拿去跟别家的尺价比，而别家的尺价通常不含五金、安装、售后。真要报，必须紧跟一句「我们这个尺价里含什么」，否则等于把自己送上比价台。

话术卡

三段式，一段都不能少：① 先给起步价与区间（让客人自己对号入座） → ② 讲清价格差在哪三件事（做几个空间／板材五金档次／有没有造型岛台） → ③ 反问，必须包含预算。第一条回复里永远不要出现算出来的具体总价。

「贵」的五种意思

客人说「太贵了」，几乎从来不是在说价格本身。先用一句反问定位，再选卡：
「我理解 —— 我想问清楚一点，是整体超出预算了，还是您觉得这个价格对应的东西不值？这两个我处理的方式不一样。」

① 没参照系
语气是惊讶不是拒绝 → 用 卡 4-1：拆解 + 使用年限换算。
② 真不够
说得出具体数字、语气确定 → 直接走 卡 3-1 局部定制，不要在价格上纠缠。
③ 怕做不好
「做不好怎么办」「你们做完就跑了吧」 → 卡 4-3：十怕十诺 + 四道关卡。这是最重要的一张。
④ 想砍价
「便宜一点啦」 → 卡 4-4：减范围，不减价。
⑤ 不是决策人
「我回去问问老公／太太」 → 卡 4-5：拿下一步时间 + 给可转发的材料。

用「80% vs 45%」这个数字之前，先确认两件事

一、45% 从哪来？行业报告还是内部估算？说不出来源和统计口径，就不要对客人讲 —— 客人一追问而你答不上来，前面建立的信任会一次性归零。二、80% 怎么算的？分子分母是什么、统计区间多长。

在核实之前，卡 4-3 只用「我们自家数字」那一版：讲最近 N 个项目里一次安装通过验收的比例，加上四道关卡的流程图。流程比数字更可信，因为它可以被验证。
