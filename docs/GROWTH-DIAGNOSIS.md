> 写于 2026-08-18。针对「生意中规中矩、lead conversion 低、客人觉得贵」这个问题。

## 0. 先说数据的局限（重要，别跳过）

本文的数字全部来自 `crm/src/seed.js` 里的 24 条 lead（文件注释写明来自 Wilson 的日报）。

**时效性**：这批数据最后更新日期是 **2026-05-26**，本文写于 2026-08-18，**过期约 3 个月**。
**完整性**：24 条是 seed 快照，**不是全量 pipeline**，而且里面一条输单记录都没有。

所以本文的结论分成两类，请分开看：

| 标记 | 含义 | 可信度 |
|---|---|---|
| 🟢 **结构性结论** | 讲的是「流程怎么被使用、字段怎么被填、系统缺什么」。这类事情不会因为过了三个月就变。 | 可直接采信 |
| 🟡 **数值性结论** | 讲的是「转化率多少、哪个渠道好」。样本小 + 过期。 | **只当假设**，等新数据验证 |

## 2. 诊断：客人为什么觉得「贵」

一句话：

> **你们把能比价的东西交给了客人，把不能比价的东西锁在了后台。**

拆三层：

### 第一层 — 你唯一交给客人的可比物，就是价格

客人手上有你的 3D + 报价，也有另外两家的 3D + 报价。三份摆在桌上，**唯一能横向对比的维度就是那个数字**。
当只剩一个维度可比，最低的那个赢。

这不是客人贪便宜，是**你没有给他第二个维度**。

### 第二层 — 你真正的差异化，客人在签约前看不到

repo 里这套东西，在马来西亚定制柜市场是罕见的：

- V-SMOOTH 六章节，每章有 Gate，不过不放行
- 28 项空间问卷、20 项现场量尺核查表
- 安装期每日报告 + 退场前 4 项安全检查（水 / 电 / 门窗 / 清理）
- 缺陷追踪、验收签核、客户可看的进度分享视图

但它 **100% 发生在客人付钱之后**。

客人是在用「相信你会做好」的价格，买「你确实会做好」的交付。
**中间那道缝，就是「很贵」。**

### 第三层 — 免费 3D 把你的方案变成了别人的报价单

8 套免费设计流出去，客人拿着你的图去问别家价钱。

你做了整条链上**最贵的那一段**——理解需求 + 空间规划 + 出图；
别人只需要照着你的图报一个数字。

**你在替竞争对手做售前。**

## 3. 破局：五个动作

按 ROI 排序。动作五是前置条件。

### 动作一：设计从免费改成收费 ⭐ 最高杠杆

**做什么**
Stage 2 → Stage 3 之间加一道收费闸：**RM 1,500 – 3,000 的「空间诊断费」，成交后 100% 抵扣货款。**

**为什么有效（一个动作解决三件事）**
1. 筛掉不买的人 → 设计产能立刻回到真正的买家身上
2. 客人付了钱就产生承诺感 → 后面每一步的配合度都不一样
3. 竞争对手拿不到你的图

**风险，说清楚**
Stage 2→3 的数量会掉，可能掉一半。**这是目的，不是副作用。**
所以要换指标：不要再盯 lead 数，改盯「**每套 3D 带来多少成交额**」。

**怎么验证**
别全改。挑一个销售（或一个渠道）跑 6–8 周 A/B，另一边照旧，用数据决定。

**现在就能做的一件事**
Mr Lim 是唯一付过设计费的零售客，Arvindd 是唯一付过定金的。
问你的团队：**这两单的推进质量，跟另外 8 单免费的比，有没有差别？**
这个问题不需要等新数据，今天开会就能回答。

### 动作二：把报价改成「不可比」的结构

**做什么**
停止给一个总数。报价拆成四块，每块都写明「低价方案通常怎么做」：

| 项目 | 你们写什么 | 对照栏 |
|---|---|---|
| 板材等级 | 基材 / 甲醛等级 / 封边工艺 | 低价方案通常用什么 |
| 五金品牌 | 铰链、滑轨、气撑——**写型号，不写「进口」** | 低价方案通常用什么 |
| 工艺 | 拼接方式、收口、现场修边 | 低价方案通常怎么做 |
| 交付保障 | ← **这块是你们的独家** | 别人没有 |

**关键动作**：主动给客人一张对比表，让他**拿去问别家**「你们这四项分别是什么」。

你等于把比价的战场从「总价」换到了「配置」——而在配置这个战场上，你是有优势的。

### 动作三：把 V-SMOOTH 从交付工具变成销售工具

**一样新东西都不用建**，只是把时点从「签约后」提到「签约前」：

- 六章节 + Gate → 印成一页纸，**报价时一起给**
- 安装日报 / 客户分享视图 → 展厅现场用平板打开一个**在施工的工地**给客人看
- 28 项空间问卷 → 不要当内部表格，当成「我们比别人多问 28 个问题」的**证据**
- 验收签核 + 缺陷追踪 → **写进合同条款**，把流程变成承诺

`invite/` 那套邀请函动线（「有理由的邀请 ≠ 欢迎参观」）方向已经对了，
再往前推一步：**让客人在看到报价之前，就先见识到你们的交付纪律。**

### 动作四：处理渠道结构 🟡 等新数据验证

如果新数据也是快照这个形状，那么：

- **ZXL 占 76% 成交额 = 集中风险。** 要么复制出第二、第三个 ZXL（ID 公司 / 装修联盟 / 设计师渠道），要么这个风险一直挂在那里。
- **社媒别停，但要改定位。** 它现在不是获客渠道，是**信任背书**渠道——转介绍来的客人会先去翻你的 IG 再决定要不要来。所以内容要换：用**成交单的交付实录**（日报照片、安装过程、验收现场）去填，而不是堆效果图。`studio/` 那个内容工作台素材现成。
- **转介绍必须变成流程，不能靠运气。** 交付完成、客人最满意的那一刻，是唯一该系统化索取转介绍的时点。你们已经有 handover 流程 + Drive 照片，只是加一个动作。

### 动作五：开始记录输单（前置条件，不做前面四个都是猜）

三件事，都在现有 CRM 上改：

1. 任何 lead 冷掉 30 天 → **强制**标 `Dropped` + 选输单原因
   （价格 / 时间没对上 / 决策人没搞定 / 输给竞品 / 客户自身原因 / 失联）
2. 决策人设为**出正式报价前必填**——见不到签字的人，不出正式报价
3. 导出补上：首次接触日、进入 stage 日期、决策人、输单原因

没有这三样，「conversion 很低」永远只是一种感觉。

## 4. 我需要你提供什么

分四组，按价值排序。标 ⭐ 的是**不给我就只能继续猜**的。

### A. 数据

1. ⭐ **CRM 全量导出**（不是那 24 条）—— 全部 lead，含已经没成的。CSV / Excel 都行。
2. ⭐ **输单名单**：过去 12 个月没成的客人 + 输给了谁 + 对方大概报多少。
   销售凭记忆写都行，**比没有强 100 倍**。
3. 过去 12 个月按月：新 lead 数 / 出报价数 / 成交数 / 成交额 / 毛利率
4. **3–5 份真实报价单**（不同价位段）—— 我要看你们**怎么把价格呈现给客人**。这是「贵」的第一现场。
5. 广告投放：FB / IG / 小红书 每月花多少、来多少 lead

### B. 流程与话术

6. ⭐ 客人说「太贵了」，销售现在**原话**怎么回？
   （要真话，不要美化过的标准答案）
7. 从 WhatsApp 第一句到签约的完整动线：谁、在什么时候、说什么、给什么
8. 展厅数据：一个月来几组 / 出几份报价 / 成交几组
9. 设计费和定金的现行政策：什么时候收、收多少、谁可以豁免、**为什么会豁免**

### C. 竞争与成本

10. ⭐ 客人最常拿哪 **3 家**来比？他们的价格带？他们主打什么卖点？
11. ⭐ 成本结构：板材 / 五金从哪来（ZXL？中国工厂？）、目标毛利率、最低可接受价
12. ⭐ **给那 6 个成交客人各打 10 分钟电话**，问三个问题：
    - 当初为什么选我们？
    - 有没有认真考虑过别家？差点选了谁？
    - 最后打动你的是哪一句话、哪一件事？

    > 这是整份清单里**性价比最高的一项**。六通电话、两小时，
    > 能直接告诉你差异化到底该怎么说——而且不用等任何系统改造。

### D. 产能与团队

13. 设计产能：一个月能出几套 3D？现在有几套是免费的？
14. 承诺交期 vs 实际交期的差距
15. Sheerly / Reina / Wilson 各自：接了多少 lead、成交多少、平均单价

## 5. 拿到新数据后怎么跑

```bash
# 从 CRM 的 Leads 页面 Export → 存成 CSV
node docs/lead-analysis.mjs path/to/Sail_Leads.csv
```

脚本会输出本文第 1 节的同一套表（渠道转化、stage 分布、免费设计清单、
输单记录检查、决策人填写率、报价分布），方便**每个月复跑一次**看趋势。

字段容错：同时认得 CRM 导出的列名（`Source` / `Stage` / `Quotation (RM)`）
和原始字段名（`leadSource` / `salesStage` / `quotationAmount`）。

⚠ **现在直接导出会缺字段**：`leadToRow()` 没有输出首次接触日、决策人、输单原因，
脚本会在开头明确警告哪几项分析被跳过，不会默默算错。要拿到完整分析，
得先按「动作五」补这几个字段。
