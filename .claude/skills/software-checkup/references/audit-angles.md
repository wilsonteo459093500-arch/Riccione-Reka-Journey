# 体检的七个角度

每个角度：看什么、怎么查、常见的坑。软件没有的部分直接跳过。
检查员（或你自己）每个角度交回：一段总结、0–10 分、做得好的、发现（每条带证据）、不算毛病的改进点子。

每条发现的固定栏位：

| 栏位 | 说明 |
|---|---|
| 标题 | 白话，老板看得懂 |
| 严重度 | 严重 = 报给客人的钱算错、资料会丢、资料被外人看到；高 = 真的用起来很快会遇到；中 = 排进计划修；低 = 打磨 |
| 证据 | 哪个文件哪一行，或跑过的脚本 / 截图的路径 |
| 影响 | 对业务、客人、老板会发生什么事（不讲术语） |
| 建议 | 怎么处理 |
| 工作量 | 小（不到一天）/ 中（几天）/ 大（一周以上） |
| 正式版有没有 | 有 / 没有（只在没上线的那版）/ 没查 |
| 把握 | 高 / 中 / 低 —— 没查实的降把握，不要讲满 |

## 1. 钱对不对（有报价、价格、金额的软件必看，排第一）

- 写小脚本直接调用真正的计算函数，算几个真实的例子，对照文档里写的规则。
- 同一份单子在每个输出（画面、PDF、Excel、WhatsApp 文字、长图）的总价要一样；**逐行加起来也要等于小计**。
- 边界输入：0、负数、超大、空白、打错单位（米打成毫米）、逗号小数。先看计算函数，再看画面上有没有挡住 —— 函数不挡但画面挡了，就不算问题。
- 折扣：不该打折的项目有没有被打折（**每个版本都要看**，例如设计师净价版）；折扣能不能超过 100% 或变负数；有没有上限 / 要不要批准。
- 价格表改了以后，旧单子是照新价重算还是冻结？单子上有没有记是哪一版价格？
- 「自动加进来」的东西（AI 建议、模板默认值）和手动加的，同样的尺寸价钱一样吗？

## 2. AI 功能（没有就跳过）

- 用哪个 model、每次大概多少钱、要等多久、等的时候用户看到什么。
- 回复坏掉、超时、被拒绝时会怎样；有没有人能把额度刷光（限流、每月上限）。
- AI 的结果进到正式资料之前，有没有人核对那一步（原则：AI 只能建议、不能编）。
- AI 读出来的数字（比例、尺寸）错了，会直接变成钱吗？差多少会差多少钱？
- 客人的资料（户型图、照片）送去哪里、存多久。
- 反馈有没有真的回到规则 / 测试里。

## 3. 安全与隐私

- **仓库是不是公开的**：价格表、折扣规则、客户资料、内部文件有没有在里面。
- 登录、每个人看得到 / 改得到谁的资料（Supabase 的 RLS 规则对照实际设定）、谁改了什么有没有记录。
- 钥匙有没有被 commit 进去；服务器接口有没有验身份、验输入。
- 同事离职怎么办（账号、他手机里的本机资料）。
- 用到的套件有没有已知漏洞，实际用到的路径受不受影响（例：只导出不读入的 Excel 套件，读入的漏洞就碰不到）。

## 4. 资料会不会丢

- 两个人（或两台设备）同时改同一份，会怎样？有没有提醒？
- 用设备时间比新旧的，手机时间不准会怎样？
- 离线、同步到一半失败、本机空间满。
- **有没有备份 / 一键导出全部 / 还原**；免费方案的资料库会不会因为没人用被暂停。
- 改错了能不能找回上一版。

## 5. 实际操作体验

- 真的打开来用：手机（390×844，触控）和笔电（1280×800）各走一遍主要流程，截图。
- 先跑软件自带的浏览器测试（有的话），再自己走：第一次打开 → 做出一份能发的单子要点几下、多久。
- 找：步骤太多、业务看不懂的词、藏太深的功能、看不懂的错误提示、手机上被挡住或挤出去的东西。
- 给客人看的输出够不够专业、完整（有效期、「预估」声明、条款、公司联络、业务名字、单号、日期）。
- 这台机器的中文字体只有一种，丑不算问题；看版面、用词和流程。

## 6. 代码与上线流程

- 测试有多少、最重要的行为有没有测到；有没有自动检查挡住坏掉的版本上线。
- **正式版是怎么上线的**：从哪条分支、要不要手动、合并后会不会自动更新；软件在不在 main 里。
- 很大的文件、重复的逻辑、第一次打开要下载多大。
- 文档和实际对不对得上（**文档说「和旧系统同一个资料库」，要实际去看是不是**）。
- 新对话接手容易吗：`CLAUDE.md` 有没有提到这个软件、计划文档在哪。

## 7. 业务缺口

- 先看懂公司的流程（客人进来 → 需求 → 报价 → 提案 → 签约 → 交付），这个软件管哪一段。
- **有没有人真的在用**；没有的话，是缺什么让他们换不过来（这个要问老板，见面试第二轮）。
- 对照真实工作缺什么：单子的状态（草稿 / 已发 / 成交 / 没成）、单号、谁做的、折扣权限、和其他软件的衔接（不要重复打字）、统计。
- 按「对业务的帮助 ÷ 工作量」排，不是按好不好做排。
