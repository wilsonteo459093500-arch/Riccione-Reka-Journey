## 一、工艺细节（看「缝、角、边、面」）

| 名称 | 一句话（整理稿） | 对客人的好处 | 怎么认出来（看图 / 看标注） | 常见位置 | 状态 |
|---|---|---|---|---|---|
| **脱缝**（也叫离缝） | 柜体和墙、顶、旁板之间刻意留一道均匀的凹缝 | 柜子像「浮」在空间里，更轻；也能吃掉墙面不平 | 柜边与墙 / 墙板之间一条整齐的阴影线 | 通顶柜、柜墙一体、门套 | 待审 |
| **追缝** | 不同柜子、门板、墙板之间的缝**对齐成一条线** | 整面墙看起来是「一体设计」，不乱 | 几组柜子的横缝 / 竖缝连成一线 | 柜墙一体、厨房吊柜与高柜 | 待审 |
| **对纹** | 相邻门板的木纹接得上，像同一块木头 | 大面木作更整、更贵气 | 几扇门的山纹连续不断 | 衣柜、电视墙、通顶柜 | 待审 |
| **对开混拼**（VISN 木皮拼贴） | 宽 220 mm 以上的山纹木皮从中间裁开再随机拼，山纹与直纹自然接上（VISN 原图文字） | 天然木皮尺寸有限，拼得好才有整墙的自然感 | 整墙木皮山纹、直纹交替但不突兀 | 大面木饰墙、衣柜 | 待审 |
| **铣槽** | 在门板边上铣出凹槽当拉手 | 无拉手、立面干净，不勾衣服 | 门顶 / 门侧一道凹进去的槽 | 橱柜、衣柜、浴室柜 | 待审 |
| **拉槽** | 门板表面铣出一条条竖向凹槽（凹凸纹理） | 有节奏感和手感，单色也不单调 | 门面一排细竖槽 | 餐边柜、电视柜、岛台侧面 | 待审 |
| **斜切** | 门板 / 抽屉面的边做斜角 | 斜边本身就是拉手；立面显薄、利落 | 抽屉前端看到一道斜面 | 抽屉、床头柜、橱柜 | 待审 |
| **斜拼** | 两块板在转角 45° 拼接，木纹 / 边线绕过转角不断 | 看不到板材断面，像一整块实木 | 转角处一条 45° 线，纹理连续 | 柜体转角、台面包边 | 待审 |
| **海棠角** | 阳角不做成尖直角，而是做出一个内凹的小台阶 / 小方角（取自传统家具的海棠角） | 不磕手、不易崩边，转角有细节、有东方味 | 柜子外转角有一个小凹口、多一道阴影 | 柜体外转角、台面角、高柜立板 | 待审 |
| **夹心 / ABA 夹心** | 层板或边框用「A 料 + B 料 + A 料」三层叠，侧面露出中间那道对比色线 | 层板看起来更薄、更精致；有设计细节 | 层板 / 门框侧边中间一条深色或金属细线 | 层板、展示柜、门框 | 待审 |
| **骨骼线** | 柜面上凸出的竖向 / 横向线条，既是结构感也是拉手 | 不用另装拉手，立面有家具感 | 门与门之间或门边凸起的木条 | 衣柜、厨房、餐边柜 | ⚠️ 用溪岸官方理念 |
| **圆弧** | 柜体、墙板、台面做成弧形 | 动线更顺、更安全，空间变柔和 | 弧形柜体 / 弧形墙 | 玄关、转角、岛台、过道 | 待审 |
| **格栅** | 一排间隔的木条做隔断或柜面 | 通透、透气，有分区又不封闭 | 等距木条 | 隔断、玄关、电视墙 | 待审 |
| **钢琴键** | 竖条长短 / 进出不一，像钢琴键 | 比格栅多一层节奏和立体感 | 竖条前后错落 | 隔断、背景墙、柜门 | 待审 |
| **铣型** | 在板上铣出造型（半圆拉手、图案等） | 拉手和造型一体，有个性 | 门板上铣出的弧形 / 图形凹位 | 柜门、抽屉面 | 待审 |
| **隐形门** | 门和墙板 / 柜门做平、不留门套 | 整面墙干净，门「消失」 | 墙板上只有一圈细缝 | 卧室门、储物间、柜墙一体 | 待审 |
| **透气** | 板上铣出一排透气缝 | 鞋柜、设备柜不闷、不臭 | 柜脚 / 柜面一排细长缝 | 鞋柜、电器柜、空调位 | 待审 |
| **发光背板** | 柜内背板做成整块发光（灯箱） | 展示更有氛围，酒柜、展示柜的主角 | 柜内背板整面亮 | 酒柜、展示柜、吧台 | 待审 |
| **硬碰** | 两种材质直接对接、不加收边条 | 立面极简、线条干净（对工艺精度要求高） | 石材台面与木 / 金属直接碰，没有压条 | 台面、岛台、柜墙交接 | 待审 |

## 二、设计手法（看「体块怎么组合」——柜墙 / 玄关 / 电视墙）

| 名称 | 一句话（整理稿） | 效果 | 状态 |
|---|---|---|---|
| **悬挑** | 结构一端固定、一端悬空伸出（栖木原文：让家具如漂浮于空间） | 轻盈、漂浮感 | 待审 |
| **叠级** | 体块一层层往前 / 往上叠 | 有层次，不呆板 | 待审 |
| **错位** | 体块上下 / 前后错开，不对齐 | 打破方正，有动感 | 待审 |
| **离缝** | 体块之间留缝分开（与「脱缝」同理，放在体块组合里讲） | 体块独立、更轻 | 待审 |
| **夹吊** | 两个高体块中间夹着吊柜 / 层板 | 中间留空、通透，可做展示 | 待审 |
| **进退** | 同一立面有凸出、有凹进的体块 | 深浅对比、立体 | 待审 |
| **围合** | 体块围出一个框 / 龛 | 聚焦中间的展示或功能区 | 待审 |
| **咬合** | 体块互相嵌进去，像齿轮咬住 | 整体感强、有设计张力 | 待审 |
| **穿插** | 横板穿过竖向体块 | 线条贯穿，空间连贯 | 待审 |
| **矩阵** | 同尺寸的模块整齐重复 | 秩序感、安静 | 待审 |

> 图上标的尺寸（如 2400 mm 高、400 mm 宽、170 mm 踢脚）只是示意，不是标准；出方案仍以现场量尺和 `SKILL.md` 的净尺寸速查为准。

## 三、怎么用

- **审方案 / 给建议**：看到效果图里有对应特征 → 指出用了什么、还可以加什么；不确定是哪一种就说「看起来像 ___，请确认」。
- **写给客人**：用「对客人的好处」那一栏的说法，不堆术语；一个房间讲 2–3 个就够。
- **进 UKIR 词库**（已接上：UKIR STUDIO 展厅播放的「房间设计特点」，代码在 `blueprint/src/showroom/craft.js`）：
  程序只在方案 PDF 的图纸文字（标注、视角名、材料部位）里找这里的名称 / 别名，找到才建议（带原文），设计师打勾才播；不看图、不用 AI。
  老板逐条审「一句话」「好处」→ 状态改 ✅ → `craft.js` 里同一条改成 `status: 'approved'`（文字一字不差，`npm test` 会对）→ 才会在展厅播放里给客人看。
  待审的可以先勾，展厅播放不放（只有内部预览看得到）。之后每条再补：英文（English 版要有英文才播）、溪岸自己的特写照片、guidebook 页码。
